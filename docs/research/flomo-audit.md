# flomo 研究对照

### 1.1 flomo 功能核查与本方案映射

下表“核查结果”只概括公开资料；最后一列是本产品的设计决定。条目编号用于验收和追踪，避免开发中漏项。

| 编号 | 能力 | 公开资料核查结果 | 本 App 的落实方式 |
| --- | --- | --- | --- |
| F01 | 快速记录 | 无标题也能记录，入口多样。[F-A](../research/sources.md) | 输入、分享接收、快捷方式与小组件都通向同一草稿 |
| F02 | 语音记录 | 录音转文字，可适度整理并查看原文。[F-B](../research/sources.md) | 保留音频、原始转写和整理版；允许失败后重试 |
| F03 | 多级标签 | 支持父子标签和正文内标签。[F-C](../research/sources.md) | 层级标签是正式能力，另保留可选笔记本 |
| F04 | 每日回顾 | 可配置内容、时间范围和数量，App/桌面组件/推送参与。[F-D](../research/sources.md) | 每日固定卡组，包含/排除标签、回顾记录、免打扰 |
| F05 | 随机漫步 | 沿关联探索旧笔记，有旅程结束卡片。[F-E](../research/sources.md) | 关联跳转、弱关联跨越、返回路径、结束明信片 |
| F06 | 相关笔记 | 从当前笔记发现相关内容，可隐藏同标签结果。[F-F](../research/sources.md) | 语义关联和手动引用分开展示，支持跨主题探索 |
| F07 | 找一找 | 用自然语言问题寻找相关旧记录。[F-G](../research/sources.md) | 精确搜索与语义探索并列，结果可进入洞察 |
| F08 | AI 洞察 | 支持单条/多条、不同视角、自定义视角和来源引用。[F-H](../research/sources.md) | 独立洞察工作区，选范围、视角，异步生成并可追问 |
| F09 | Agent | 个人笔记对话、记忆、定时玩法、联网延伸与保存结论。[F-I](../research/sources.md) | 原生对话页、工具调用、可管理记忆与定时任务 |
| F10 | AI 记忆档案 | 画像、主题记忆与记忆碎片；公开说明为手动生成更新。[F-J](../research/sources.md) | 可审阅、纠正、删除、暂停更新的记忆中心 |
| F11 | 认知地图 | 内容相似度聚类展示主题，并提供时间切片。[F-K](../research/sources.md) | 全局主题地图、局部展开、时间变化，基础 2D 纳入完整版本 |
| F12 | 引用与反链 | 引用、批注、MEMO 链接可连接笔记。[F-L](../research/sources.md) | 稳定 ID 链接、批注、反向引用及手动关系图 |
| F13 | 热力图与统计 | 记录节奏、月年统计、标签等扩展图表。[F-M](../research/sources.md) | 日历热力图、主题统计；点击数字返回对应原文 |
| F14 | 高级搜索 | 日期、标签、媒体等条件，支持无标签和去年今日。[F-N](../research/sources.md) | 组合筛选、来源筛选、保存搜索条件 |
| F15 | 历史版本 | 能浏览与恢复笔记历史。[F-O](../research/sources.md) | 本地版本、AI 改写前快照、恢复差异预览 |
| F16 | MCP / API | 可连接外部 AI 搜索、读取及写入笔记。[F-P](../research/sources.md) | 有范围授权的开放接口，权限可撤销，写入可审计 |
| F17 | 同步、导入导出 | 提供多端同步及迁移入口。[F-A](../research/sources.md)[F-Q](../research/sources.md) | 增量同步与独立备份；明确冲突策略 |
| F18 | 桌面回顾、分享卡片 | 回顾组件、记录入口、笔记分享图均有产品依据。[F-D](../research/sources.md)[F-Q](../research/sources.md) | 安卓桌面组件与本地图片导出，默认不外发 |
| F19 | 图片、音频、视频 | 图文、语音明确；安卓近期更新还列出视频上传。[F-B](../research/sources.md)[F-Q](../research/sources.md) | 多媒体附件模型、缩略图、独立上传与重试 |
| F20 | 备忘录与待办 | 本项目自身的融合需求 | 长文编辑、置顶、清单、到期与提醒，保持原文关联 |

### 1.2 调研中的版本差异

- Agent 帮助页仍主要介绍微信入口，并提示以各端实际入口为准；官网指向的小米应用商店更新记录已出现 Agent 对话删除、相关笔记继续探索等内容。可确认安卓产品已有相关能力，不能把它描述成只存在于微信。[F-I](../research/sources.md)[F-Q](../research/sources.md)
- 随机漫步帮助页仍写着不能从指定笔记开始、不能保存小径历史；安卓更新已列出相关笔记“继续探索”。后者支持入口正在演进，但尚不足以确认所有平台都有完整路径历史。本 App 会明确设计“从这条开始”和“保留本次路径”，这是我们的目标能力。[F-E](../research/sources.md)[F-Q](../research/sources.md)
- 帮助页的 MCP 会员说明与安卓商店“Pro 可使用 MCP”的更新出现差异。本文不锁死 flomo 的套餐权益，功能研究也不以付费档位决定是否设计。[F-P](../research/sources.md)[F-Q](../research/sources.md)
- 地图公开说明有更新周期和样本规模限制；其可视化呈现不能当作无遗漏的全库统计。本 App 需直接显示覆盖范围与更新时间。[F-K](../research/sources.md)

### 1.3 应保留的产品气质

快速入口保持轻，不要求先分类。回顾允许闲逛，洞察允许提出问题，Agent 允许说“没有找到足够依据”。AI 提供的新内容与用户真实记录保持来源区分。视觉精致，但不让用户每天面对一个复杂控制台。
