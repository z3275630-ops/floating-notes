## 失败严重度

P0：数据丢失/越权/密钥暴露/不可恢复迁移，立即阻断。P1：核心路径不可用、可复现明显卡顿、重复写入或引用误导，阻断相关功能发布。P2：非核心布局/文案/低影响边缘问题，可记录明确修复期限，但不能掩盖视觉验收未通过。

报告包含用例 ID、构建 SHA、环境、前置数据、操作、实际结果、期望结果、是否可复现、日志/视频/trace 链接、修复 PR 和回归结果。一次通过不自动代表其他 Android 版本、设备或模型组合通过。
