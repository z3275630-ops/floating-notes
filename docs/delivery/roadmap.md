# 开发路线图与任务拆分

阶段代表依赖顺序。全部功能 F01–F20 属于完整版本，不得将 M2–M4 当作随时可以删掉的“以后再说”。当前所有任务为待开始。周期估算要等 M0 真机样例、团队容量和服务预算确认后再给；不承诺未经估算的固定周数。

| 阶段 | 目标与退出条件 |
| --- | --- |
| M0 | 原生视觉、输入、检索与 Agent 可行性；关键风险有实测证据 |
| M1 | 本地记录/编辑/媒体/待办/搜索/恢复可用 |
| M2 | 回顾、关联、找一找与漫步形成闭环 |
| M3 | 洞察、Agent、记忆和定时任务真实执行 |
| M4 | 地图、同步、迁移、组件、MCP/API 完整集成 |
| M5 | 真机审美/性能、数据安全与发布验收 |

## 首个 APK 优先路径（v3.1 提议，尚待评审）

参见 [首个 Android APK 垂直切片](first-apk-vertical-slice.md)：建议以 **T01 → T02/T03（并行）→ T04/T07（依赖满足后可并行）→ T08** 完成可在真机体验的本地记录闭环。原任务 DAG、F01–F20 范围和全部完成条件不变；不承诺固定七天工期。v3.0 目前仍是基线，只有实际实现和测试通过才更新任务/功能状态。
