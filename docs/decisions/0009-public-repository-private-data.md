# ADR 0009：仓库公开，用户数据和应用发布分别授权

日期：2026-11-08。状态：**accepted**。

此决策覆盖 ADR 0007 的“默认 private 仓库”部分，但保留旧 ADR 作为当时授权的历史记录。所有者已明确要求将 `z3275630-ops/floating-notes` 更改为 **Public**，GitHub 仓库可见性检查也已确认 public。

公开仓库允许外界读取文档、代码与提交历史；**不自动授予开源许可证**，也不等于已授权公开发布 APK、付费开通模型服务、上传私人笔记或允许第三方访问数据。

继续遵守 [SECURITY](../../SECURITY.md) 中的密钥、测试数据和安全约束。演示使用合成笔记。后续许可证、应用分发、实际数据与付费操作分别取得相应授权。未来若再切回私有仓库，已被外部克隆的内容无法保证收回。

本 PR 只记录公开仓库现状与授权边界，不执行可见性变更。参见 [STATUS](../../STATUS.md)。
