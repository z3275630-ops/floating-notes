# v3.1 增量功能实施合同

状态：accepted / 已纳入开发计划；实现状态：planned。2026-11-08 所有者要求合并并交接开发。本合同补充 v3.0；原 F01–F20、数据可靠性、视觉和性能门槛继续有效。NoteDocument / EvidenceBundle schema 保持原版本，以下派生交互状态不得偷偷写入原文。

## T35：跨应用文本收集

阶段 M1；依赖 T08；关联 F01/F18，S02/S03，Q091–Q094。基础记录 APK 完成后优先执行，不等待 T29 的桌面组件。交付系统 ACTION_SEND 文本/链接接收与 ACTION_PROCESS_TEXT 选区入口，先查官方 Android 文档并验证目标 SDK 的 manifest/exported 行为。

- 外部文字进入独立收集草稿，用户预览、修改、保存或取消。来源 URL 仅在确有来源时显示，不把任意正文猜成作者或原网页；链接不自动抓取。取消不得覆盖原编辑草稿。
- 复用 T07/T08 保存事务，按一次接收会话的 capture_id 保证旋转、进程恢复、连点只落一条。用户下一次主动分享同样文字允许新建，不能用内容 hash 永久去重。
- 本期支持纯文本和链接。空文本、异常 extras、不支持的 MIME、超过输入上限必须解释并允许退出；不静默截断。图片/文件接收另接 T10，常驻悬浮球保持可选实验。
- 来源应用未提供选中文本入口时，普通系统分享仍可使用。离线保存、磁盘满、取消、强杀恢复均验证。保存成功由数据库提交决定。
- 页面复用 S02/S03 的 GlassSurface 与 A02/A12，返回关闭当前收集流程，不清空原笔记栈。

## T36：编辑边缘的历史回响

阶段 M2；依赖 T08/T17；关联 F06，S03/S10，Q095–Q098。本期交付真实相关片段，不等待云端模型。T17 的可用本地检索路径必须保留，语义索引不可用时允许关键词检索并如实标注覆盖范围。

- 输入法 composing 结束且文字稳定 800ms 后才发起异步检索；新输入取消旧请求，返回结果必须核对查询版本。每次只展示一个紧凑提示，自动提示间隔至少 30s；手动“相关笔记”不受此节流限制。
- 提示放在编辑区域边缘的预留位置，不遮光标/候选条，不推动正文滚动，不获取焦点；点击后进入可关闭的来源面板，返回保留选区与滚动。无结果保持安静，检索失败不阻塞编辑或本地保存。
- 当前笔记、删除/回收站/排除项、未授权范围不参与候选；显示及点击前再次核对权限和 revision。缓存不允许绕过过滤；显示来源日期、真实片段及 note_id/revision/block_ids 对应关系。
- 设置全局开关和本次静默；关闭后取消任务、隐藏提示。取消动作不能影响保存。TalkBack 不自动抢读，每条建议有明确的查看/关闭操作。
- “可能矛盾”“桥接假说”在 T20 的引用、范围与模型质量通过后再单独启用；向量相似只表示相关，不能据此判定观点冲突。模型适配仍按 ADR 0008 的 proposed 状态验证。

## T37：随机漫步的双卡概念对撞

阶段 M3；依赖 T18/T20；关联 F05/F08，S09/S11，Q099–Q102。进入随机漫步后可主动切换双卡模式，保留单卡模式和清晰导航。

- 两张卡来自用户范围内不同的真实 Note，记录稳定 ID/revision/block_ids；不足两条时提示扩大范围，不编造第二张卡。卡片点击可查看原文，换一组和返回保持可复现的会话历史。
- 用户点击“寻找联系”后才调用已授权模型；展示预算/进行中/取消/失败状态。请求使用双方原文证据，输出明确标为可能关联，可点“牵强”反馈或重新生成。没有模型/网络时仍可看双卡并手写联想。
- 原文在生成期间变更或删除时标记结果失效，重新核对后再保存；不能继续把旧引文呈现为当前原文。模型不能执行来自笔记的指令。
- 保存为一条新笔记，保留来源引用与 AI 来源标识，使用幂等保存；不合并或覆写两条原记录。源记录被删时引用显示失效，不虚构原文。
- 两卡过渡复用 A07，来源展开复用 A08；窄屏/200% 字体时纵向排列，按钮操作与手势等价。不要引入无限画布或整页液滴物理模拟。

## 动效与验证

参数使用 contracts/design-tokens.json 的 v31_interactions。回响出现/退出先用 220/180ms，透明度配合最多 8dp 位移；只改变提示自身。双卡使用既有 A07 的 12–24dp 轻移，返回或连点从当前状态中断，不排动画队列。减少动画时零位移并立即切换稳定状态。

以上数值是实现起点，全部待真机验证。玻璃折射不作用于正文，渐变不持续循环；标准/增强/实色档、明暗主题、60/120Hz 和温升按既有门槛验收。不能因为赶进度删除液态玻璃和动效要求。

每项任务提交实现、失败路径、Q091–Q102 对应证据和原生录屏；UI PR 按既有性能门槛交付。无设备时先完成可编译产物，设备项标 blocked，不将未测项记为通过。具体 provider、模型和数据库扩展在对应任务内选择并记录依据，禁止提前承诺所有手机可运行本地大模型。
