分支 `feat/T14-history-backup-ui`，`versionCode 18`，`versionName "0.1.14-backup.1"`（调试包显示 `0.1.14-backup.1-debug`），关联任务 T14（F15、F17），依赖 T07、T10。预发布归档见 [v0.1.14-backup.1](https://github.com/z3275630-ops/floating-notes/releases/tag/v0.1.14-backup.1)。上轮背景见 [T13 交接](2026-11-14-T13-ui-todos.md)。

## 已完成内容

1. **T14 历史版本（S18）、最近删除（回收站）与本地备份恢复（S20 / S21）**
   - **Room v4 → v5 迁移（`MIGRATION_4_5`）**：在 `NotesDatabase` 中新增 `index_notes_deleted_at` 索引，为 `note_versions` 表扩展 `title TEXT NOT NULL DEFAULT ''` 与 `attachment_refs TEXT NOT NULL DEFAULT '[]'`，并在迁移中自动从既有 `document_json` 回填历史标题与块级附件 ID；导出并归档 [Room v5 schema](../../app/schemas/io.github.z3275630ops.floatingnotes.data.local.NotesDatabase/5.json)（SHA-256 `CBB30AD362A3E67C8ACBCC5A5EFC7A699CD0B7F2FFF24AF386BE0F089CFBCC0C`），`1.json`–`4.json` 保持原样未修改。
   - **单篇版本历史（S18 `NoteHistorySheet`）**：每次提交笔记时若标题、块结构或附件列表发生实质变化，自动写入新 `NoteVersionEntity` 快照，单篇笔记最多保留最近 `50` 个版本；支持任意版本与当前版本（或相邻版本）的标题、文本块增删改及附件引用差异对比（`NoteRevisionDiff`）；恢复历史版本采用**非破坏性追加（append new revision）**策略，保留全部既有修订记录并同步重建标签关联、反链（`note_links`）与待办提醒（`task_reminders`）。
   - **最近删除（回收站 `TrashView`）与级联清理**：移入废纸篓写入 `notes.deleted_at`（默认保留 `30` 天，启动时 `purgeExpiredTrash(30)` 自动清理超期项），从首页、笔记库、普通搜索、待办清单及侧栏文件夹计数中自动排除，并立即取消该笔记关联的 `AlarmManager` 提醒；从废纸篓恢复可清空 `deleted_at` 并重算未过期的提醒；彻底删除/清空废纸篓前提供影响预检（`TrashPurgeImpact`：展示将断开的引用反链数、将清理的提醒数与将被回收的独占附件文件数）。
   - **附件引用保护（`AttachmentStore.collectUnreferenced`）**：垃圾回收同时扫描存活笔记、草稿以及所有 `note_versions.attachment_refs`，确保历史版本或回收站笔记引用的附件不被误删；仅对目录项（`it.isDirectory`）执行 `.part`/`.old` 清理与 `BackupCodec.isSafeAttachmentId` 校验，避免误删 `filesDir/attachments/` 下的临时散落文件。
   - **本地全量 ZIP 备份、Markdown 导出与事务性恢复（`BackupCodec` / `BackupManager` / `BackupRestoreSheet`）**：
     - 全量 ZIP 备份（`manifest.json` + `snapshot.json` + `attachments/<id>/<file>`）完整打包笔记、历史版本、笔记本、多级标签、笔记双链、草稿、提醒、任务完成记录、已保存搜索与附件原文件，并写入每项附件的字节大小与 SHA-256。
     - 采用零反射 `MiniJson` 编解码（兼容 R8/ProGuard 混淆压缩）与确定性排序输出。
     - 安全防护：ZIP 读取强制校验相对路径（拦截 `..` 路径穿越、绝对路径与符号链接）、限制条目数与解压体积（`maxEntries = 10,000`、`maxTotalUncompressedBytes = 2 GiB`、`maxSingleEntryBytes = 256 MiB`、`maxCompressionRatio = 100`）、校验附件 ID 白名单及 `StatFs` 可用空间。
     - 恢复预检（`RestorePreflight`）与双模式恢复：支持**完整覆盖（`FULL_REPLACE`）**与**合并保留较新项（`MERGE_KEEP_NEWER`）**（按 `updatedAt` 合并，同名笔记本与同路径标签自动重映射 ID）；恢复前默认创建当前库保护备份，并通过 `restore-journal.json`（含 `DB_COMMITTED` 状态位）保障异常中断回滚与闹钟重排。
     - 支持一键导出人类可读的 Markdown 归档 ZIP（含 YAML frontmatter、块级 Markdown 正文与相对路径 `attachments/` 附件）。

2. **Apple Notes / iOS HIG 深度视觉与交互改造（无实时模糊）**
   - **无模糊分层表面与配色**：遵循 [视觉规范](../design/visual-system.md)，停用 Android 12+/13+ 实时模糊（`RenderEffect` / `RuntimeShader`），统一使用高帧率不透明 iOS Grouped Surface 分层色板（浅色 `#F2F2F7` 底 + `#FFFFFF` 卡片，深色 `#000000` 底 + `#1C1C1E`/`#2C2C2E` 分组容器、0.5dp 分割线与 `#0D9488`/`#2DD4BF` 品牌强调色）。
   - **通用组件与核心页面升级**：
     - 升级 `MintControls`（iOS 滑块式 `MintSegmentedControl`、48dp 触控行高 `MintGroupedRow`、三段式弹窗顶栏 `MintSheetTopBar`、圆角填充搜索框 `ComposablesSearchField`）。
     - 重构首页 `NotesShell`、侧栏抽屉 `NotesDrawer`（iOS 备忘录文件夹列表，新增 `"最近删除"` 计数入口与 `"设置与数据管理"` 入口，且在 `NotesDrawerTest` 中补齐长列表滚动定位）、全屏编辑器 `NoteEditor`（右上角 `⋯` 更多菜单整合笔记本归档、标签、版本历史与移入废纸篓，底部精简为单行胶囊工具栏）与快速记录浮层 `CaptureSheet`。
     - 修复 `CaptureSheet` 拖拽把手（`capture-handle`）下滑手势：移除 `onDragStart` 中导致 `.imePadding()` 瞬时坍缩的 `keyboard?.hide()`，使用 `rememberUpdatedState(panelHeight)` 保持 `.pointerInput(Unit)` 在输入法高度变化时不重启，并通过 `.onGloballyPositioned` + `LayoutCoordinates.localToRoot` 在屏幕根坐标系下计算 1:1 拖拽位移与速度（阈值 `motion.progress < .65f || velocity > 650.dp.toPx()`）。
     - 新增并打磨 `NoteHistorySheet`、`TrashView` 与 `BackupRestoreSheet`（顶栏副标题精简为单行 `"本机 ZIP 与 Markdown"`，杜绝窄屏断行）。
