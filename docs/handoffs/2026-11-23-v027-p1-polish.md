## 2. 本轮落地改动清单（P1-01 ～ P1-14）

1. **存储生命周期、语音缓存与大库备份流式化（`P1-01` ～ `P1-03`）**
   - **`P1-01` 回收站 30 天自动清理与提示对齐**：`NotesRepository` 新增 `TRASH_RETENTION_DAYS = 30L` 与事务性 `purgeExpiredTrash(now, retentionDays, excludeNoteIds)`；`NotesViewModel.onForeground()` 在前台启动后通过 `purgeExpiredTrashIfNeeded()` 自动清理超期（> 30 天）已删笔记（排除正在打开的草稿）并同步清理片段、提醒与无引用附件；`TrashView.kt` 横幅明确提示“启动时自动清理”。
   - **`P1-02` 语音转写坏缓存自愈与提交后关闭弹窗**：`TranscriptionDialog.kt` 中 `TranscriptionStore.readResult()` 捕获 JSON 解析或缺失字段异常后自动删除损坏 `transcript.json` 并返回 `null` 以便重试重新识别；`EditorSession.insertTranscript` 返回 `Boolean`，`TranscriptionDialog` 与 `AttachmentRow` 仅在插入返回 `true` 时关闭弹窗；`BackupModels.kt` 的 `DEFAULT_EXCLUSIONS` 补充 `"uninserted_audio_transcripts"`。
   - **`P1-03` 一致性事务快照、流式 JSONL 与块 ID 去重**：`BackupManager.captureSnapshot` 纳入 `database.withTransaction` 保证时间点一致，并移除 `stagedParsedArchive` 常驻内存缓存；`BackupCodec` 对 `metadata/versions.jsonl` 与 `metadata/drafts.jsonl` 改用 `writeJsonlStreamed` / `readAndVerifyJsonLines` 流式读写；`VersionDiff.parseBlocks` 校验并拒绝包含重复块 ID 的文档。

2. **检索精度、回响新鲜度与回顾状态准确性（`P1-04` ～ `P1-08`）**
   - **`P1-04` 多音词拼音、长段落切片与大库模糊池扩容**：`ChinesePinyinTable` 抽出 `IndexedSyllable` 与高频多音词词表 `COMMON_POLYPHONE_PHRASES`（如“银行/重要/会计/长度”等，同时保留“成长 -> chengzhang”），并由 `LocalFuzzyMatcher` 复用；`LocalRetrievalEngine.buildChunks` 通过 `splitLongSegment` 按 ≤ 220 字切分超长块；`SearchRepository.observeSmart` 将模糊匹配候选池从 `500` 扩至 `maxOf(limit * 4, 20_000)`。
   - **`P1-05` 回响新鲜度核验与异步增量建索**：`LocalRetrievalEngine.freshChunksFor` 在 `searchEvidence` 与 `computeRelatedNotes` 中同时比对 `noteRevision` 与 `contentHash`；`DiscoveryRepository.verifyEdgeEchoHit` 在版本或哈希变化时校验摘录与 `matchedBlockId` 是否仍匹配最新正文；`NotesViewModel` 在常规自动保存、外部合并重试及待办变更提交后调用 `syncChunksAsync` 增量更新索引。
   - **`P1-06` 回顾已看原子去重、FSRS 去通胀与未展卡优先**：`ExploreScreen.ReviewTabContent` 改为通过 `LaunchedEffect(review.session.id, card.note.id)` 在实际展示卡片时记录一次（移除翻页点击及 `NotesViewModel.selectReviewCard` 中的重复写入）；`DiscoveryDao.insertReviewEventIfAbsent` 在同会话同笔记已有 `"seen"` 时保留首次时间；`FsrsReviewScheduler.deduplicateSameSessionEvents` 按 `(sessionId, day)` 折叠多余浏览信号（由 `"annotated"` 吸收 `"seen"`，同时保留同会话后续 `"deferred"` 失误判定并兼容跨日历史事件）；`DiscoveryEngines.selectDailyReviewNoteIds` 在同日再抽一轮时优先展示未出场笔记。
   - **`P1-07` 回顾会话与游标并发保位**：`DiscoveryDao` 新增 `latestReviewSessionForDayAndConfig`、`reviewSessionsForDay`、`updateReviewSessionIndex` 及稳定排序 `ORDER BY round DESC, updated_at DESC, id DESC LIMIT 1`；`DiscoveryRepository` 事务化更新页码与移卡动作并保留 `currentIndex` 相对位置。
   - **`P1-08` 英文小数断句与字符预算一致**：`LocalTextIntelligence.splitSentences` 新增 `isAsciiSentencePeriod` 防止 `3.14` 等英文小数被错误拆句；`extractKeySentences` 让返回的 `sentences` 列表与 `joined` 共用 `maxChars` 字符上限。

3. **查重聚类、双卡对撞、待办联动与性能隐私闭环（`P1-09` ～ `P1-14`）**
   - **`P1-09` 查重星型聚类与历史报告一致性**：`LocalTextIntelligence.findDuplicateGroups` 改为以主笔记为核心的星型聚类（替代易链式漂移的并查集）；`LocalAgentEngine.AgentRunResult` 持久化 `duplicateGroupSnapshots` 与 `timeRangeName`，`AgentRepository` 新增 `hydrateDuplicateGroups` 避免运行后二次全库扫描并保留真实 `runId`（`NotesViewModel.commitMergeDuplicateGroup` 传入 `run?.id`）。
   - **`P1-10` 双卡对齐语料与快照联动刷新**：`LocalTagAndGraphEngine.selectBestDualCollisionPair` 仅使用合格笔记语料；`DiscoveryRepository` 新增 `analyzeDualCollisionRefreshed` 返回 `Ready` / `Unavailable`，当源笔记变更时刷新卡片与桥接洞察，若已删或设为排除则明确提示换组。
   - **`P1-11` 待办紧迫度协同与跨午夜刷新**：`TasksScreen` 在 `ON_RESUME` 与跨午夜 `LaunchedEffect` 自动刷新 `currentToday` 与 `currentZone`，并为“即将”列表接入紧迫度评分二级排序；`LocalAgentEngine.analyzeTodoTriage` 读取真实 `ReminderEntity`（识别逾期/错过/延后/重复状态）；`TaskUrgencyEngine` 将搁置理由更正为 `“所在笔记已 X 天未更新”`（保留原有徽标标签）。
   - **`P1-12` 移除主线程重计算**：`SearchRepository.observeSmart` 与 `NotesRepository.observeTaskItems`（补充同 emission 内单篇文档缓存解码）切换至 `Dispatchers.Default`；`NoteEditor.InlineSuggestions` 改为 `remember` + 惰性 `asSequence()`；`NoteEditorDiscovery.EditorRelatedNotesSheet` 与 `AgentWorkspace` 重复合并预览均改用 `produceState` 在后台线程准备文本与摘要。
   - **`P1-13` 大库查重分桶优化、细粒度取消与标签推荐去重**：`LocalTextIntelligence.findDuplicateGroups` 当候选大于 200 篇时先做 SimHash / IDF 桶粗筛，并在关键循环内插入 `checkCancelled()`（`LocalAgentEngine.analyze` 同步透传取消检查）；移除 `NotesViewModel.onEditorTextActivity` 中的冗余标签推荐触发，并在 `DiscoveryRepository` 增加 `cachedTagCorpus` 语料缓存。
   - **`P1-14` 统一 `aiPolicy == "exclude"` 隐私边界**：将 `exclude` 过滤统一落实到 `LocalTagAndGraphEngine`（k-NN 与标签共现）、`LocalTextIntelligence.findDuplicateGroups`、编辑器回响（`findBestEdgeEchoCandidate` 使用 `aiOnly = true` 且 `verifyEdgeEchoHit` 拒绝 `exclude`）及双卡选卡/关联洞察；`AgentWorkspace` 隐私说明条已更新明确展示统一保护范围。

4. **版本号与新增回归测试**
