# T11 前台录音与状态栏交接

分支 `feat/T11-voice-capture`，实现提交 `3eec079`，基底 T10 `7e48faf`。T11 对应 F02，依赖 T10 与 T08。

- **状态栏**：把首页和跨应用收集的背景画到屏幕边缘，仅为可操作内容留出系统栏空间。沿用 Compose 玻璃面板和薄荷绿主题，并匹配浅色、深色启动窗口底色。荣耀 X10 的日间首页已拍摄前后对照。
- **前台录音**：编辑器点“录音”主动申请麦克风权限。录音可暂停、继续、停止，单段上限 10 分钟。切到桌面会结束采集，尝试保存已录部分。音频经 T10 校验写入草稿，保留 M4A 原件，保存失败可重试。Room schema 沿用 v2。
- **权限与构建**：新增 RECORD_AUDIO，按需授权。使用 Android 官方 [MediaRecorder](https://developer.android.com/media/platform/mediarecorder) 和 [Compose 边到边布局](https://developer.android.com/develop/ui/compose/system/setup-e2e)，复用 T10 附件校验、原件存储和预览入口。开发预览版 versionCode 12。
- **待续**：T11 的转写适配器、原文/整理版、断网队列和同一任务重试仍待实现。Android 10 的系统识别接口不适合已录音文件，新版本的音频源参数也由识别服务决定是否支持。候选离线方案 [Vosk Android](https://github.com/alphacep/vosk-android-demo) 尚需验证小模型在旧机的中文质量和成本。电话真实中断、进程被杀时未封口的音频、锁屏和临近上限未演练。T09 待办仍见 [交接](2026-11-09-composables-ui.md)。

## 验证

Windows 英文构建路径执行 `gradlew.bat --no-daemon --max-workers=2 "-Pkotlin.compiler.execution.strategy=in-process" assembleDebug assembleDebugAndroidTest lintDebug testDebugUnitTest` 成功。Lint 0 错误、40 警告。JVM 测试为 NO-SOURCE。Debug APK v2 签名通过。文档检查与 Git diff 检查通过。

荣耀 X10（Android 10 / API 29）短时验证：先用系统权限框拒绝并核对提示，再用 ADB 仅对调试包准备录音授权状态。前台录音、暂停/继续、停止并写入草稿、回到桌面后自动停止并保存均通过。复核音频附件目录后还原测试授权状态。安全保留原测试包数据并覆盖安装，未使用模拟器。ADB 一度显示离线，主机端重启调试服务后恢复。电池读数约 29℃。

同机使用 AndroidJUnitRunner 执行 22 项回归，全通过。为保留既有笔记，跳过依赖干净列表的 `BootstrapTest` 和固定引用名称的 `LocalRecordingTest#insertReferenceAndOpenItsBacklink`，这两项曾在 T10 干净测试数据下通过。本轮状态栏对照只覆盖日间首页，深色、夜间启动与高版本玻璃仍待测。
