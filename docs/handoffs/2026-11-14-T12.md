# T12 中文搜索与筛选交接

分支 `feat/T12-local-search`，应用源码 `dc80a35`，迁移测试修订 `816954d`，基底 `ce87c8e`。T12 / F14，依赖 T07、T09。笔记库复用 Composables UI 搜索框，可按标题或正文搜索，并组合日期、标签、笔记本、来源、媒体与归档。日期支持创建/修改时间和去年今日。标签支持匹配任一或全部、排除子树及仅无标签。保存搜索记录名称、关键词与 NoteScope v1 条件，调用时读取当前数据库关系。

实现沿用项目 [Android 平台方案](../engineering/android-platform.md) 与 [SQLite 文档](https://www.sqlite.org/fts5.html)。当前使用 Room 的参数化子串查询，字面匹配标点和通配符，英文 ASCII 忽略大小写。搜索在后台执行，按 50 项逐步展示。FTS5 trigram 的短词限制与本次需求不符，后续以性能数据决定是否加索引。所有筛选维度取交集，排除标签优先，删除的笔记始终不参与搜索。

Room 升至 v3。迁移 2→3 为笔记补齐可重建的媒体标记并新增 saved_searches 表，旧文档、草稿和附件路径保留。1→2→3 使用原有引用迁移链。已有笔记的筛选继续读当前标签关系；备份与恢复阶段需同时纳入保存的搜索条件。

## 实际验证

- Windows 英文构建路径运行 `gradlew.bat --no-daemon --max-workers=2 "-Pkotlin.compiler.execution.strategy=in-process" assembleDebug assembleDebugAndroidTest assembleRelease assembleBenchmark lintDebug testDebugUnitTest` 成功。Lint 0 错误、41 警告。JVM 测试无源码。R8 仍有 Kotlin 元数据警告。
- Windows 上编译实际的 Kotlin 查询生成逻辑，并在 SQLite 3.50.4 执行 8 组子串和组合范围用例，全通过。旧库迁移 DDL 与 Room v3 导出的各表列定义一致。一万条合成笔记补充测得高命中首屏 P95 3.26 ms、无命中 10.32 ms。该结果仅含桌面内存 SQLite 查询。
- 荣耀 X10 USB 接口可见，ADB 重启与重连后仍报告离线。真机覆盖安装、Compose 操作、Room 迁移测试以及 1 万条真机 P95 尚无结果。本地未启动模拟器。远端检查见 [GitHub Actions](https://github.com/z3275630-ops/floating-notes/actions?query=branch%3Afeat%2FT12-local-search)。
- 测试 APK 可从 [GitHub Releases](https://github.com/z3275630-ops/floating-notes/releases/tag/v0.1.12-search.1) 下载，versionCode 14，v2 签名通过，SHA-256 `8370caf268c11738c381434c3a11aff11dda8d0379358d0a16fca26702629893`。同签名可覆盖安装。Room 更新到 v3 后，用 v2 旧包覆盖回滚会遇到数据库降级问题。卸载会清除本机数据。

## 荣耀 X10 复验及玻璃界面

USB 调试在切换主机 ADB USB 后端并重连后恢复。用测试包覆盖安装，从 v2 真实升级到 v3，原笔记与草稿可见。初版发现搜索控件已变化但列表未刷新，修复为让页面过渡内的列表读当前状态。调试包 `295110e` 在 Android 10 上的 T12 和笔记组织 8 项全通过，覆盖中文、标点、组合范围、保存/重新应用条件与 v1/v2 升级。一万条合成笔记查询 P95 首屏有结果 55.83 ms，无匹配 194.25 ms，调试构建与内存数据库，仅计查询。电池温度约 30℃。

[视觉规范](../design/visual-system.md) 新增 Apple 风原生界面验收。首轮样板覆盖笔记库、静态多点弥散背景、胶囊快速记录、玻璃导航、搜索弹层。旧设备走现有轻量材质分级，使用染色和渐变边光。更高版本实时模糊、深色样张、TalkBack 和动画帧耗时待验收。

组合回归初跑 27 项中 26 项通过。拖拽测试使用固定像素，在荣耀 X10 的高像素密度下没拉够关闭距离。按密度换算同一实际手势距离后，该用例单独复测通过。两个依赖干净测试数据的既有测试跳过，保留手机当前数据。最终调试与测试 APK 构建、Lint 0 错误/41 警告、签名与文档检查通过。新版见 [v0.1.12-search.2](https://github.com/z3275630-ops/floating-notes/releases/tag/v0.1.12-search.2)，APK SHA-256 `f556f2f5b5248285da86efc74d6b5ab41b7d4b5a9164b266b7d50608270e9e80`。
