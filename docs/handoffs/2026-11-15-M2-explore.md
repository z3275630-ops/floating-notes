# M2 探索闭环（回顾、共享索引、找一找、漫步与边缘回响）及 iOS 一致性打磨交接

分支 `feat/T15-m2-explore`，`versionCode 19`，`versionName "0.2.0-explore.1"`（调试包显示 `0.2.0-explore.1-debug`），关联任务 T05、T15、T16、T17、T18、T36（F04、F05、F06、F07）。预发布归档见 [v0.2.0-explore.1](https://github.com/z3275630ops/floating-notes/releases/tag/v0.2.0-explore.1)。上轮基线见 [T14 交接](2026-11-15-T14-apple-ui.md)。

## 已完成内容

1. **T05 / T16 共享本机检索与语义相关索引（Room v5 → v6）**
   - **Room v5 → v6 迁移（`MIGRATION_5_6`）**：在 `NotesDatabase` 中新增 `note_chunks`、`review_sessions`、`review_events`、`walk_sessions`、`walk_steps` 五张表及对应索引；更新 `BackupModels.SUPPORTED_DB_SCHEMA_VERSION = 6` 与 `BackupManager` 全量覆盖前对发现表的前置清理，并在备份恢复完成后自动触发索引重建。导出并归档 [Room v6 schema](../../app/schemas/io.github.z3275630ops.floatingnotes.data.local.NotesDatabase/6.json)（SHA-256 `B83CC46EF83C0F10230E5F204EDD4FD1605A35C21E4E93AC1384F21525EA13EC`），`1.json`–`5.json` 保持原样未修改。
   - **纯 Kotlin 本机分词与邻接片段合并（`LocalRetrievalEngine`）**：按 220 字符窗口合并相邻正文与待办块，提取中英文词汇、2-gram / 3-gram 及查询停用词裁剪词项（`tokenizeForIndex` / `buildQueryTerms`），零依赖 Android `org.json` 运行时；提供 `NoteScope` 作用域（活跃/归档/时间范围/标签子树与排除）以及已删除/已排除双重门槛实时过滤，严格排除当前笔记自身。
   - **T05 可行性结论（已落地验证）**：在 Honor X10（Android 10）端上，针对中文短记与结构化块，纯本机词频归一化 + 共同标签子树权重 + 双链关联度 + 时间邻近衰减的混合打分模型在冷/热启动下索引全库 175 篇笔记仅耗几十毫秒，且可即时透明汇报 `RetrievalCoverage`（可检索总篇数 / 已覆盖最新 revision 篇数 / 滞后篇数），无需引入重型端侧向量库即可稳定覆盖 M2 召回与解释需求。

2. **T15 每日回顾与那年今日（`DiscoveryEngines` / `DiscoveryRepository` / `ExploreScreen`）**
   - **同日稳定卡组与配置隔离**：基于 `LocalDate` 与稳定种子选出当日回顾卡组（默认每天 5 篇，可配置 3/5/8 篇、最近编辑权重与偏好标签范围），同日退出/重进/跨页切换严格复用当日持久化 `ReviewSessionEntity` 顺序与位置；调整配置仅对下一新轮次或“加练一轮”生效，不静默篡改正在进行的当天卡组。
   - **回顾动作与批注闭环**：支持查看详情跳回原笔记、“稍后再看”后移、基于原笔记新建 `@[[...]]` 双链批注、“7 天内不再出现”临时静默、“不再出现在回顾中”永久排除，以及在「那年今日」卡片真实回看往年同月同日笔记（无记录时如实引导，不编造历史内容）；「设置与数据管理」支持一键恢复全部已排除内容。

3. **T17 相关笔记、自然语言找一找与证据篮（`ExploreFindAndWalk` / `EditorRelatedNotesSheet`）**
   - **相关笔记（S03 / S10）**：在全屏笔记编辑器顶部胶囊（`✦ 相关笔记 N`）与相关面板中实时计算并展示关联笔记及可解释原因标签（直接引用、反向引用、共同标签、主题内容相近、相近时间记录），并支持“从此漫步”。
   - **找一找与证据篮**：支持自然语言提问、快捷提问胶囊、作用域筛选（活跃笔记 / 含已归档、时间范围、标签子树）、提取词项展示、索引覆盖率指示与手动“刷新索引”；零命中时如实说明当前范围未命中并给出放宽建议；支持勾选证据条进入“证据篮”，一键汇总为带 `@[[...]]` 溯源引用的新笔记。

4. **T18 随机漫步与路径明信片**
   - **70/20/10 加权漫步**：支持自由出发或按标签主题出发；每步约 70% 沿紧密脉络延伸、20%“换个方向”跨主题衔接、10%“意外遇见”久未翻看记录；支持路径节点完整回退（“回到上一条”）、在途中卡片记录灵感随想，并展示中文步骤理由标签。
   - **漫步明信片（含隐私开关）**：可生成路径与沿途摘录明信片，切换“隐私保护：隐藏正文摘录与标签”开关即时脱敏路径摘要，支持复制全文或存为新笔记。

5. **T36 编辑边缘历史回响（`EditorEdgeEchoStrip` / `EdgeEchoPreviewSheet`）**
   - 在笔记编辑器正文输入停顿后（>= 30s 间隔、非中文 IME `composing` 状态、全局未关闭、单篇/全库未静默且当前文档仍与索引一致时）由数据库实时复核后在顶部/底部轻提示条浮现最相关的历史笔记；点开可预览并跳转到原笔记或记录新关联，点关闭或永久忽略后立即取消并持久化，不阻断编辑与保存流程。
   - 在「设置与数据管理」中提供“写作边缘历史回响”全局开关与“恢复已排除的回顾与发现内容”入口。

6. **iOS HIG / Apple Notes 组件一致性打磨（无实时模糊）**
   - 在 `MintControls.kt` 新增定制 Apple 风格 `MintSwitch` 拨片与 `MintActivityIndicator` 状态指示，替换 `BackupRestoreSheet.kt`、`NoteHistorySheet.kt`、`NotesShell.kt` 中的原生 Material `Switch` 与 `CircularProgressIndicator`，消除其余页面中的“安卓工具味”组件并保持 Honor X10 零实时模糊高帧率渲染。
