## 已完成内容

1. **Apple 备忘录风薄荷玻璃 UI 重构与暗色/旧系统对比度修复**
   - 遵循 [视觉规范](../design/visual-system.md) 与主题 token，重构首页（`NotesShell`）、侧栏抽屉（`NotesDrawer`，将实验/示例工具折叠进可滚动的 `"开发与实验"` 分区）、快速记录浮层（`CaptureSheet`）、独立全屏编辑器（`NoteEditor`）与笔记库智能文件夹/筛选弹窗（`LibrarySearch`）。
   - 全屏编辑器强化首行标题层级与正文留白，展示创建/更新时间、可点击笔记本与标签胶囊、本机保存状态与 `FlowRow` 底部工具栏（待办、附件、录音、`@ 引用`、`标签`），已有笔记编辑态保留右上角主 CTA `"完成"` 并移除底部重复 `"保存"` 按钮。
   - 修复 `GlassTier.Reduced`（Android 10 / API 29）不透明背景、禁用态主按钮对比度（`GlassAction`、`MintPillButton`）、`ComposablesSearchField` 清除按钮内边距以及暗色模式卡片/标签对比度，并保留所有 `@` / `Clickable` 无水波纹显式交互源规范。

2. **T13 待办清单与本地定时提醒（S01 / S23）**
   - Room 升级至 v4（`Migration(3, 4)` + `NotesDatabase.migrations`），新增 `task_reminders`（`ReminderEntity`）与 `task_occurrences`（`TaskOccurrenceEntity`），迁移保留既有笔记、草稿、笔记本、标签、附件与已保存搜索；导出并校验 [Room v4 schema](../../app/schemas/io.github.z3275630ops.floatingnotes.data.local.NotesDatabase/4.json)。
   - 实现 `TaskRecurrence`（基于 `ZoneRules` 处理夏令时与非 UTC 午夜时区、`FOLLOW_LOCAL` / `FIXED_ZONE` 策略、每日/每周重复推进及逾期汇总批次）、`AlarmManager` 调度（`ReminderScheduler`）、通知交互接收器（`ReminderReceiver`，支持稍后 15 分钟与完成）及开机/改时/改时区重算（`BootTimezoneReceiver`）。
   - 首页 S01 新增 `"全部 | 待办"` 分段筛选、待办未完成计数与到期提醒徽标；新增全屏待办清单 S23（`TasksScreen`：`今天` / `未来` / `已完成`、`"默认进入待办视图"` 启动偏好、复用 `MintGlassDialog` 的 `TaskScheduleModal`），并打通 `TasksScreen` 与 `NoteEditor` 之间的双向勾选与重复推进状态同步（通过 `NotesViewModel` `persistenceMutex` 串行化持久化）。

3. **T09 剩余范围补全（行内 `#` / `@` 与引用选区）**
   - 编辑器在 `TextFieldState.composition == null` 时触发不抢占输入焦点的行内建议栏（`#` 现有/新建标签按 `tagId` 绑定；`@` 整篇或选段引用插入并写入 `note_links` 反链）。
   - 支持框选来源笔记区块与 UTF-16 代码单元 `[start, end)` 引文范围（`clampUtf16Range` / `safeUtf16Slice` 避免拆分代理对），将 `target_block_id`、`start`、`end`、`target_revision` 写入块 JSON 并更新 [笔记文档契约](../../contracts/note-document.schema.json)。
