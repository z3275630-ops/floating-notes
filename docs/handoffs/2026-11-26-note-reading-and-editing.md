# T08 笔记阅读页、光标落点与触感

- 任务 T08，功能 F01、F20，依赖现有 T04 快速记录和 T07 本地保存。
- 工作分支为 fix/editor-data-audit，基于 dba62f2 上同一轮未提交的审查修复。
- 已有笔记默认呈现阅读页。点正文或所在行的右侧空白可落光标，点勾保存并回到原笔记阅读态。带区块 ID 的入口在阅读态定位原块。快速记录仍走原先的保存和草稿流程。
- 复用 Compose 文本布局计算光标，单击兜底只处理子控件没有接收的点击。拖排、扫选、文本选区和段尾菜单的手势继续走原路径。
- 阅读和编辑复用同一个笔记会话与滚动列表。阅读模式让正文使用完整宽度，编辑保留段尾控件空间。浅色与深色使用低饱和纸面，工具栏只在编辑时显示。
- Android 使用系统触感接口完成待办勾选、编辑保存与现有长按拖排反馈。依赖手机的触感设置。数据库、权限、备份格式及正式签名均无需变动。

参考了 ColorOS 16.7.8 安装包内编辑器的坐标定位、Apple 备忘录的结束编辑与格式入口、Notion 的正文与页边手势分工、flomo 的记读分离。复用浮记的原生编辑器与系统反馈接口。

## 段间光标补修

- 荣耀 X10 复现普通方向键在单段内可以左右移动，右键到段尾时不会进入下一段。每段对应独立的 Compose 输入框。
- 在没有修饰键、选区或拼音组合时，由 EditorBlockEngine.kt 复用已有焦点迁移流程处理段间接续。NoteEditor.kt 只在跨过当前字段边界时接管方向键。
- 本次覆盖安装调试版并通过 21 项真机编辑器回归，包括段内双向点选和拖柄、左右键跨段、拖排、选段和保存重开。157 项 JVM 测试与 Lint 也通过。
