# 编辑器与数据审查修复交接

基线为 `main` 的 `dba62f2`，工作分支为 `fix/editor-data-audit`。覆盖 T08 编辑器、T12 检索、T13 提醒、T14 备份恢复、T25 认知地图，以及外部笔记导入。需要升级的 Room 版本仍为 v8，完整备份版本仍为 v2。

## 修复范围

- 保存进度和合并基准跟随实际提交的文档与序号。写入期间发生的编辑留给下一次保存。
- 合并恢复单独处理草稿。原槽位可用时恢复到原笔记，有本地冲突时保留独立副本。草稿待绑定标签与提醒待设参数进入备份，通过原恢复日志续接文件晋升。
- 恢复预检与执行按记录校验，正文和历史记录暂存到磁盘，再分批写入同一 Room 事务。极大单条记录和元数据文件会收到明确的大小错误，还原前的回滚包内存不足会先中止。
- 外部导入以单条最终数据库行的实际字节数做保护。英文词中搜索由原有 FTS 结果和字面子串分支共同覆盖。认知地图先查询轻量选样信息，只读取入样笔记的有限正文，支持取消计算并限制共享标签候选。
- 提醒是否已通知独立于排期版本。过期动作不能停止或更新新的提醒。中文候选与正式文档分开，外接键盘撤销经过应用的段落历史，收起键盘后的撤销保留原来的键盘状态，标签和引用成功后才清掉触发词。
- 左右横滑都在松手时判定。选块支持在勾选列连续扫选，选中样式和勾选控件使用预留空间。长按拖排有按压反馈，沿用现有色彩、卡片和动效体系。
