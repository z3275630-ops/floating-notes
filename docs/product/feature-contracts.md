# 20 项功能验收合同

版本 3.0；全部纳入完整版本。状态表在 contracts/feature-catalog.json；当前均为 planned。每项必须关联页面、数据、测试、任务与实现证据。验收用例在 docs/quality/test-cases.md。

## F01 · 快速记录

**实施阶段：M1；页面：S01/S02/S03；主要对象：Note、Draft、ChangeEvent。**

入口与前置条件：首页 + / 分享接收 / 桌面快捷方式。打开后输入焦点直接可用，标题与标签可留空。

主行为与状态：输入 → dirty → saving → local_saved；显式保存生成 Note，非空关闭保留 Draft。连续点击使用同一提交 ID。

失败与边界：磁盘满、进程死亡、URI 失效时保留可恢复内容；不显示假成功。

最低验收结果：输入 200 字，连续保存两次，只生成一条；重开内容一致。

对应测试：Q001/Q002/Q003。功能说明：[规格](../features/capture-editor.md)。未通过错误、恢复、权限或关联数据用例时，不能以主流程可点击为由标为完成。


## F02 · 语音记录

**实施阶段：M1；页面：S04；主要对象：Attachment、Transcript、Draft。**

入口与前置条件：用户主动点麦克风后申请权限；录音期间显示时长、暂停和停止。

主行为与状态：idle → recording ↔ paused → recorded → transcribing → transcript_ready；整理版独立生成。

失败与边界：录音原文件在 ASR 失败后仍可播放；电话中断和后台限制明确反馈。取消转写不删除音频。

最低验收结果：断网后录音保存，恢复网络仅重试一次转写，原文/整理版可切换。

对应测试：Q004/Q005/Q006。功能说明：[规格](../features/capture-editor.md)。未通过错误、恢复、权限或关联数据用例时，不能以主流程可点击为由标为完成。


## F03 · 多级标签

**实施阶段：M1；页面：S05/S06；主要对象：Tag、NoteTag。**

入口与前置条件：正文 # 与库页管理共用稳定 tag_id，路径只用于展示。

主行为与状态：创建/重命名/移动/合并均走校验；移动父节点会影响完整子树路径。

失败与边界：拒绝循环；同父重名要求合并或改名；删标签不删笔记。

最低验收结果：A/B 移到 C 后所有关联仍在；尝试把 A 移进其子节点被阻止。

对应测试：Q007/Q008/Q009。功能说明：[规格](../features/capture-editor.md)。未通过错误、恢复、权限或关联数据用例时，不能以主流程可点击为由标为完成。


## F04 · 每日回顾

**实施阶段：M2；页面：S07/S08；主要对象：ReviewSession、ReviewEvent。**

入口与前置条件：探索首页显示今日卡组与完成进度，可改包含/排除标签和时间范围。

主行为与状态：按用户时区的日期生成稳定卡组；看过、暂缓、排除此条分别记录。修改配置只影响新卡组，重建当前需明确动作。

失败与边界：无材料显示去记录/放宽范围；跨设备优先使用已同步的当天会话。

最低验收结果：同日退出重进卡序不变；排除标签中的笔记从活动查询立即消失。

对应测试：Q010/Q011/Q012。功能说明：[规格](../features/discovery.md)。未通过错误、恢复、权限或关联数据用例时，不能以主流程可点击为由标为完成。


## F05 · 随机漫步

**实施阶段：M2；页面：S09；主要对象：WalkSession、WalkStep。**

入口与前置条件：探索开始或从某条笔记继续，提供返回、换方向、结束。

主行为与状态：取候选 → 去重与排除 → 显示下一条 → 持久化路径；back 沿既有路径，不重新抽样。

失败与边界：候选耗尽显示换范围/结束；离线用缓存或标签关联并标明；不强迫总结。

最低验收结果：连续走 10 步，返回 3 步再前进，已走路径可复现；结束卡片计数准确。

对应测试：Q013/Q014/Q015。功能说明：[规格](../features/discovery.md)。未通过错误、恢复、权限或关联数据用例时，不能以主流程可点击为由标为完成。


## F06 · 相关笔记

**实施阶段：M2；页面：S03/S10；主要对象：NoteChunk、RelatedResult。**

## F08 · AI 洞察

**实施阶段：M3；页面：S11/S12；主要对象：Insight、EvidenceBundle、Perspective。**

入口与前置条件：单条、选区、多选和范围都可发起；生成前预览数量、范围与费用上限。

最低验收结果：报告所有引用可定位到版本；继续聊继承证据；保存仅生成有 provenance 的新笔记。

## F09 · Agent

**实施阶段：M3；页面：S13/S14；主要对象：Conversation、AgentRun、ToolAction。**

## F16 · MCP/API

## F17 · 同步与导入导出

**实施阶段：M4；页面：S20/S21；主要对象：SyncOperation、Tombstone、BackupManifest。**

入口与前置条件：本地导出在 M1 可用；完整版本包含增量同步、冲突副本、完整恢复。

主行为与状态：事务+outbox → push ack → pull cursor；导入独立暂存校验；恢复先生成当前备份。

最低验收结果：双设备离线改写/删除再上线无静默丢失；损坏备份不能清空现库。
