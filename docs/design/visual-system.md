# 液态玻璃与渐变视觉系统

## 原生界面验收

浮记采用 Apple 液态玻璃的层级与交互思路，使用薄荷绿、雾白和浅芽绿形成低饱和度的弥散光场。Android 端继续使用 Kotlin、Compose 和现有 Composables UI 组件。默认 Material 外观须定制，尤其是悬浮操作按钮、实色顶栏、按压水波纹和高对比应用底栏。系统状态栏和系统导航保持可用，应用内容与边缘背景自然衔接。

- **环境与内容**：浅深色分别设计多个静止柔光区域，避免硬边色带和大面积平涂。阅读卡片使用稳定的雾面，与背景通过留白和柔和明暗区分。正文和光标保持清晰。
- **玻璃控制层**：重点用于悬浮导航、快速记录面板与当前弹层。亮面边缘为薄渐变高光，背光边减弱，可加轻微内缘明暗。控制高成本背景采样的面积。Android 10 等旧设备使用多层渐变、半透明染色与边缘高光表现玻璃厚度。
- **轮廓与排版**：主容器优先 22–28dp 圆角，内部控件约 14–16dp，短按钮可用胶囊轮廓。中文沿用可读的系统字体，标题中粗，次要文字按最终合成对比度调色。卡片留白优先，避免贯穿屏幕的硬分隔线和黑灰硬阴影。
- **反馈与可访问性**：应用内主要触控可以用轻微压缩、染色及可中断弹簧回弹。系统减少动画和减少透明度设置生效，保留清晰焦点及触控区域。具体模糊和回弹参数由真机测量决定。

首批样板为笔记库、底部导航、快速记录入口和搜索弹层。验收看真实操作中的光影、文字、按压和连续返回，覆盖荣耀 X10 的降级材质与支持实时模糊设备的玻璃效果。参考 [Apple HIG 材质](https://developer.apple.com/design/human-interface-guidelines/materials) 与 [Android RenderEffect](https://developer.android.com/reference/android/graphics/RenderEffect)。

## 5. 视觉设计系统

### 5.1 主视觉：雾白、薄荷绿、浅芽绿

浅色底色接近带一点暖意的白，局部光晕由薄荷绿过渡到雾白，再从浅青绿收进浅芽绿。渐变主要位于背景顶部与操作区附近，中间阅读区域保持稳定。

| 语义 | 浅色建议 | 深色建议 | 使用方式 |
| --- | --- | --- | --- |
| 页面底色 | #F4F8F2 | #0D1914 | 全页面基底 |
| 正文表面 | #FAFDF9 或高不透明度近白 | #182720 | 笔记与编辑区 |
| 主文字 | #182B21 | #E7F3EA | 长文与标题 |
| 次文字 | #435B4D | #BED1C4 | 时间、辅助说明 |
| 品牌强调 | #126543 | #95E5B9 | 少量选中状态与关键操作 |
| 背景光色 | #BFEBD4 → #F4F8F2 → #E0F3EB → #E7F2C7 | 深色底上降低亮度的对应光晕 | 装饰，不能直接充当小字底色 |
| 错误 | 深红并配文字 | 浅红并配文字 | 保存失败、权限问题 |

颜色是初稿，需在实际透明层合成之后测对比度，不能只核对独立色值。普通文字以至少 4.5:1、较大文字以至少 3:1 作为验收目标。按钮状态也要有形状或文字变化，不能仅靠颜色区分。

### 5.2 玻璃分级

| 等级 | 放置区域 | 效果 |
| --- | --- | --- |
| G0 内容面 | 笔记卡片、正文、长列表 | 稳定实底或很高不透明度，无实时折射 |
| G1 轻玻璃 | 顶部工具条、非高频浮层 | 染色、细边缘高光、柔阴影；可有有限背景模糊 |
| G2 重点玻璃 | 底部导航、笔记侧栏、快速记录面板外壳 | 背景采样、有限模糊、边缘折射、少量交互形变 |

玻璃需要让人看到厚度和背景层次。仅把卡片透明度调低，往往会让页面显得灰脏。反过来，折射过强又会让文字附近像水波，容易晕。

重点控制以下参数：背景采样区域、染色强度、透明度、边缘高光方向、曲率、阴影和状态切换。正文及按钮标签单独绘制在效果层上方，保持清晰。

初始限制：同一页面常驻高成本玻璃区域控制在 1–2 个；弹出输入面板时隐藏或降级后方导航，避免多层玻璃相互采样。该数量只是调试起点，最终由实际 GPU 成本决定。

### 5.3 间距、圆角、字体

| 项目 | 初始规范 |
| --- | --- |
| 间距刻度 | 4、8、12、16、20、24、32dp |
| 页面水平边距 | 手机默认 20dp，窄屏可降为 16dp |
| 卡片圆角 | 20dp |
| 大面板圆角 | 28dp；与系统窗口形态协调 |
| 胶囊导航 | 按高度形成自然胶囊，不给所有组件套相同圆角 |
| 页面标题 | 28–30sp，中等字重 |
| 正文 | 16sp 起，按系统设置缩放 |
| 辅助信息 | 12–13sp 起，不能承载关键操作说明 |
| 图标 | 统一 22–24dp 线性图标；触摸区至少 48×48dp |

采用系统中文字体与统一图标集。不要为“高级感”大量使用极细字重或加载整套巨大中文字体包。48dp 触摸区域参考 Android 无障碍指导。[S9](../research/sources.md)

### 5.4 深色与无障碍

深色主题单独设计：降低光晕亮度，提高玻璃染色密度，减少灰白泛光。提供减少透明度后的清晰实底方案。

验证系统大字体、TalkBack、减少动画、色觉差异和深浅色切换。表单与弹层要正确转移焦点，关闭后返回原按钮。选中、待办完成、保存失败都要有可读语义。

### 5.5 需要交付的设计资产

设计资产覆盖记录、快速输入、录音转写、完整编辑、笔记库、待办、精确搜索/找一找、探索首页、每日回顾、随机漫步、洞察报告、Agent、记忆中心、定时任务、认知地图、授权与数据管理。每页覆盖深浅色与必要的空白、加载、失败、资料不足和权限拒绝状态。

组件清单：GlassSurface、玻璃导航、笔记卡片、标签胶囊、输入面板、编辑工具栏、搜索结果、待办行、状态提示、确认弹层、来源引用卡、AI 范围选择器、任务进度、漫步工具条、地图底部面板。组件使用统一 token，不允许每页自己调整圆角和主题色。

### 5.6 新功能怎样保持同一种美感

- 漫步：当前笔记是清晰内容面，路径与动作落在玻璃工具条；过渡短、可中断，正文不跟着折射。
- 洞察：报告如一张干净纸页，来源标记清楚；“继续聊”和范围面板使用统一材质，避免多彩 AI 卡片抢占正文。
- Agent：输入栏轻玻璃，消息正文稳定；工具过程折叠，只在需要时看来源和操作记录。
- 地图：背景柔和但坐标与轮廓清楚；主题颜色保持稳定，不用渐变颜色表达未经定义的分数。
- 记忆：信息密度适中，事实、待核实、过期状态用文字与标记组合表达，方便纠正。

上一版只有记录/笔记/待办的交互示意不再代表 v2 导航。本轮交付以更新后的规格为准，后续原型应按这些关键页重新制作。

## V01：明确的美术方向

主视觉是雾白阅读面、薄荷绿与浅芽绿的柔和环境色、具有边缘厚度的玻璃控制层。第一眼应感到精致、明亮、有呼吸感；阅读时眼睛能稳定落在文字。避免饱和霓虹、炫彩油膜、大面积发光描边、全屏透明和厚重拟物阴影。

页面有四层：环境背景；内容面；悬浮玻璃控制层；临时模态层。正文卡片可以有极轻的环境染色，但不能让每张卡片各自折射背景。当前操作所在的玻璃表面最突出，后方表面减少高光与采样，避免互相争夺注意。

## V02：材质构成与初始参数

| 参数 | 标准浅色 | 标准深色 | 约束 |
| --- | --- | --- | --- |
| 环境渐变 | #BFEBD4 → #F4F8F2 → #E0F3EB → #E7F2C7 | 低亮度的苔绿与深青，避免白色泛光 | 色标插值在组件内部统一，主题切换避免中间脏灰 |
| G1 染色覆盖 | 白色约 0.78 | #182720 约 0.84 | 根据实际合成背景校验对比度 |
| G2 染色覆盖 | 雾白约 0.58 | #182720 约 0.80 | 不将值直接当作整体控件 alpha |
| G2 模糊半径 | 16dp | 16dp | 引擎采样单位由适配器转换，避免混淆 dp/px |
| 顶侧高光 | 白色 0.94，1dp | 白色 0.34，1dp | 不围出完整亮白边框 |
| 底侧边缘 | 绿边 0.27，1dp | 绿边 0.32，1dp | 和阴影合成后检查边缘脏色 |
| 阴影 | 12dp 阴影，深青绿 | 12dp 阴影，深青绿 | 不给内部文本投影 |
| 边缘折射 | 15dp 边带内最大位移 4dp | 同浅色 | 光学示意参数，须经真机调校 |
| 噪声 | 默认 0；出现色带时评估极轻纹理 | 同左 | 不引入持续随机闪烁 |

这些是调参起点，不是实测结论。任何改动通过 token/材质适配器集中生效。模糊半径、渐变位置与折射场不能每帧引起大范围布局重算。

## V03：渐变构图

记录页只在顶部标题附近和底部导航后方出现宽而淡的色域；阅读正文区域维持较均匀背景。探索页可用更大的浅青绿色团承接每日回顾，但卡片内文字仍在稳定阅读面。Agent 页主要在输入区与当前工具状态点使用色彩。地图允许主题分类颜色，颜色只标类别，不暗示人格或价值排名。

渐变停靠点以归一化坐标定义，屏幕旋转保持视觉重心，不按像素拉伸导致色团被裁掉。360dp 与 412dp 宽度各有构图检查。背景默认静止；首次进入可做一次极轻显现，完成后停止。系统减少动画时直接显示最终构图。

## V04：标准组件及职责

| 组件 | 必须支持的状态 | 验收重点 |
| --- | --- | --- |
| GlassSurface | normal/pressed/focused/disabled/reduced | 前景清晰、边缘无黑线、内容采样不递归 |
| FloatingNavigation | 4 个 tab/选中/大字/键盘/隐藏 | 选中指示连续移动，图标和文字保持可读 |
| NotesDrawer | 关闭/拖动/打开/范围选中 | 侧栏切换全部、归档、笔记本和标签，底栏保留四个主页面 |
| CaptureSheet | collapsed/expanding/editing/saving/error | 与键盘同步，失败不丢草稿 |
| NoteCard | plain/media/pinned/selected/deleted-source | 长文本截断稳定，媒体加载不跳高度 |
| ScopePicker | chips/expanded/invalid/empty | 排除条件可见，清除条件有明确作用范围 |
| EvidenceChip | valid/stale/deleted/blocked | 可点到原文，不能只靠颜色区分 |
| ToolProgress | queued/running/cancelling/complete/fail | 实际状态，不能播放虚假进度百分比 |
| WalkToolbar | next/back/change/end | 单手触达，走到边界有解释 |
| MapSheet | collapsed/half/full | 手势不与地图拖拽抢事件 |

## V05：全量视觉交付要求

必须产出组件目录、24 页关键状态、浅/深色样张、360dp 和 412dp 布局、横屏或折叠展开适配、大字体与减少透明度效果。每份画面标注版本、对应 screen ID 与 token 版本，不能交付孤立无版本图片。

主流程需原生可操作样例：快速输入/键盘，列表/导航玻璃，漫步/返回，Agent 流式内容，地图/底部面板。至少展示连续快速操作 15 秒，不能只给剪辑后的慢速转场。

## V06：审美验收清单

- 玻璃有背景层次、柔化、高光与厚度，文字不透脏。
- 薄荷绿渐变在深浅主题均克制，背景静止也完整，不依赖永动动画撑场面。
- 一套字号、间距、圆角、图标；同一动作跨页面材质和反馈一致。
- UI 在真实中文长内容、多个标签和长按钮文案下依然成立。
- 降低特效后仍保留配色、光线方向和层级，不能退回无设计的默认组件拼盘。
- 产品所有者明确通过视觉样例；工程人员通过质量门槛。二者证据链接存入验收记录。
