# 动效、手势与丝滑体验合同

## 6. 动效与跟手体验

| 操作 | 建议表现 | 初始时间范围 |
| --- | --- | --- |
| 按下按钮 | 很轻的压缩与高光变化，释放立即回弹 | 80–140ms |
| 页面切换 | 短距离位移配合透明度，保留空间关系 | 180–260ms |
| 输入面板进入 | 从触发位置附近展开，与系统键盘同步 | 约 220–320ms；以系统动画进度为准 |
| 笔记打开 | 小幅容器扩展或普通转场；测试通过后再引入共享元素 | 200–300ms |
| 完成待办 | 勾选反馈、文字状态变化、位置平滑调整 | 120–200ms |
| 删除/归档 | 行高收拢并提供撤销 | 160–220ms |

这些数值是调参起点。弹簧动画由阻尼和刚度定义，实际时长随距离和初始速度变化，不能机械套用固定毫秒数。

硬性行为：动画可中断；连点不排队播放；手势返回跟随手指；后台和不可见页面停止动画；系统减少动画时移除大幅形变与位移。录入中的文字绝不跟着容器弹跳。

背景默认静止。允许主题切换时短暂过渡，首页进入时很轻的光色变化；不要常驻循环漂浮渐变。

安卓键盘的 WindowInsets 是布局依据。不要自行猜测键盘高度，再给整页叠加一套上下平移动画，这会造成双重位移、底部空洞和光标被遮挡。[S3](../research/sources.md)

### 6.1 AI 与地图带来的额外负载

模型输出按短时间窗口批量更新界面，避免每个 token 都重组整页。自动滚动只在用户本来位于底部时生效；用户上滑查看来源后，新增回复不得把他强拉回底部。

向量索引、音频处理和地图布局在后台调度；编辑输入和屏幕渲染具有更高优先级。省电模式可暂停非紧急索引，显示覆盖状态，仍允许明确发起的查询。

页面切换保留漫步位置、洞察滚动和 Agent 输入草稿。性能档位只降低视觉成本，不能悄悄取消引用校验或数据保存。

## M01：所有动画共用的行为

输入一发生就反馈。动画负责表达当前状态，不能成为执行动作前的等待。目标状态变更时从当前渲染值、当前速度继续，取消旧目标；禁止先归零再重新播放。业务提交与装饰动画解耦，动画中断不取消已提交保存。

事件按稳定 interaction ID 去重。双击保存只生成一条笔记；快速连点导航只前往最后的目标，不能排出多个返回栈。按下反馈从 pointer down 开始，滑出控件或 cancel 时恢复，不触发点击。触觉跟随真实成功事件，遵循系统设置。

## M02：关键动效逐项定义

| ID | 场景 | 起点与终点 | 触发与中断 | 不可接受表现 |
| --- | --- | --- | --- | --- |
| A01 | 导航选择 | 选中胶囊移到目标 tab，轻微形状伸展 | tap 立即改目标；反向点击沿当前速度回转 | 每次从第一个 tab 起飞、文字整体扭曲 |
| A02 | 打开输入 | 捕获按钮外壳扩大为面板，内容淡入 | 手势返回沿展开进度收回；新文字从原生输入层显示 | 硬切矩形、键盘双重抬升、焦点延迟 |
| A03 | 面板拖拽 | 面板位置与手指位移一一对应 | 松手按速度和距离决定吸附；反向拖拽立即跟随 | 超长弹跳、拉不到底、关闭后触控被遮罩拦截 |
| A04 | 笔记展开 | 卡片容器到详情阅读面 | 返回可逆；源项离屏时使用普通短转场 | 位图放大造成正文模糊、滚动位置丢失 |
| A05 | 勾选待办 | 图标与文字样式同步更新 | 立即撤销可逆；列表重排等状态确认后执行 | 点击时整页重排、勾选却未保存 |
| A06 | 归档/删除 | 项目收拢，相邻项补位 | 提供撤销；保存失败恢复并解释 | 空洞残留、误删后无恢复 |
| A07 | 漫步下一条 | 内容轻移 12–24dp 并交叉淡入 | 下一条未就绪保留当前；快速返回取消未完成预取 | 卡片转圈、强制滑完、加载时出现空白 |
| A08 | 来源展开 | 来源 chip 展开底部原文面板 | 不丢报告滚动；关闭回到引用位置 | 跳入新页面后找不到原问题 |
| A09 | Agent 输出 | 块级内容连续增长 | 上滑停止跟随；新段落短淡入可关闭 | 每个 token 动画、整页跳动、强拉到底 |
| A10 | 地图缩放 | 手势锚点固定在手指位置 | fling 可中断；sheet 拖拽在专属把手区 | 点主题后全图随机重新布局 |
| A11 | 主题切换 | 颜色与材质平滑转到新主题 | 遵循系统；减少动画直接切换 | 中间帧白闪、图标失去对比度 |
| A12 | 保存反馈 | 保存中 → 本地成功图标 | 与事务完成绑定，短反馈后安静 | spinner 永动、先成功后落盘失败 |

## M03：可复现参数

统一 token 的时间单位为 ms，距离为 dp。普通出现初始使用 220ms、离开 180ms、微反馈 100ms。用于位置吸附的 Compose 弹簧候选阻尼比 0.85、刚度 500，仅作为 M0 调参起点；文字/正文禁用可见 overshoot。运动距离小的控件优先提高刚度、限制回弹幅度，不照搬长距离面板参数。

固定时间曲线候选进入 `cubic-bezier(0.2, 0, 0, 1)`，离开 `cubic-bezier(0.4, 0, 1, 1)`；Compose 适配器需要转换并记录实际效果。弹簧和固定曲线不可同时作用于同一位置属性。系统键盘、预测性返回使用系统进度，不能用固定 250ms 猜测。

状态恢复保存业务位置而非动画中间值。进程重启到稳定状态；不重播上一轮删除动画。后台、遮挡和 offscreen 页面暂停装饰性动画，恢复时直接显示当前状态。

## M04：玻璃的交互变化

按压轻微缩放 0.985 起、高光位置偏移 1dp 起；松手回到正常。关键捕获按钮展开时可与面板边缘做连续曲率过渡，效果库支持合并表面时先验证多指、快速反复和销毁重建；不将库演示中的夸张液滴直接套用。

普通文字与图标不随折射场扭曲。可变形的是玻璃轮廓和环境采样。按压渐变不得跨越文本对比度底线。自动画质降级发生在稳定页面边界，避免同一次拖拽过程中材质突然改变。

## M05：验收录像脚本

在 release 构建、固定刷新率、设备温度稳定后：打开 → 连续切换 4 个 tab → 立刻记录 20 字 → 收放键盘 5 次 → 保存 → 快速滚动 10 秒 → 打开笔记再中途返回 → 进入漫步连续 next/back → Agent 输出时上滑 → 展开来源 → 旋转屏幕。完整录屏，不剪掉失败。

同步留存帧时间/抖动报告。单独录像不足以证明 120Hz。至少覆盖 60Hz 中低端真机与 120Hz 主力机，必要时加用户日常 OPPO/其他 OEM 手机；型号未知时记录待补，不凭空写成已验证。

## M06：无障碍替代

系统动画缩放为 0 或应用减少动画开启时，禁用大位移、形变和视差；保留可读状态变化，必要淡入不超过 100ms。减少透明度使用明确实体底色。TalkBack 焦点不能被动效移到不可见位置；没有手势能力的用户可通过按钮完成全部动作。
