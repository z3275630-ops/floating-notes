# 页面与交互状态规格

默认手机画布以 dp 定义，360dp/412dp 两档检查；页面外边距 20dp（窄屏 16dp），主要触控区不小于 48dp。底部栏包含系统手势安全区；弹层不覆盖输入法候选区。所有页面沿用统一 token 与原生输入组件。

每页必须覆盖浅色、深色、200% 字体（必要重排）、TalkBack、系统动画关闭、离线。横屏/宽屏采用列表-详情双栏或最大内容宽度，不把窄屏卡片横向拉满。下表正文描述是布局规格，未代表已产出高保真图。

## S01 · 记录首页

**布局：**顶部日期/搜索，单列笔记流，底部 G2 导航与 +；首屏最多一条置顶区摘要。

**交互：**主操作为 +；待办/全部筛选固定可见；滚动恢复依赖 note_id + offset。

**状态：**加载旧缓存；无笔记邀请写第一条；错误显示本地数据并重试；离线徽标仅在相关操作时出现。

**返回与恢复：**保存该页范围、滚动锚点与未提交输入；关闭 modal 焦点回到触发控件。业务状态改变后重新验证来源权限。跨页导航使用稳定 ID，不把全文塞进路由。

## 跨页面统一规则

点击结果后先显示本地已有内容，网络补充独立加载。加载中的按钮保留稳定宽度。失败提示说明发生了什么、内容是否安全、下一步能做什么；不用“未知错误”作为唯一信息。

焦点顺序按视觉顺序；模态开启时背景对无障碍不可达；关闭后恢复触发焦点。纯图标有语义标签，选中状态使用语义与文字，颜色不承担唯一含义。

所有长操作支持离开页面；回到列表能看见实际状态。取消是请求，不保证撤回已经提交的写入。未保存草稿、待同步内容、已在云端保存、已备份四种信息独立呈现。

验收采用合成中文资料：30 字短记、3 万字长文、8 个长标签、横图/竖图/超大图、无媒体、多语混合与 emoji。英文占位文案验收无效。
